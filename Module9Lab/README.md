# Module 9 Lab

Starter folder for the Module 9 lab, a Razor Pages app called Northwind. The project boilerplate, Bootstrap, and both nav links (Customers and Products) are already wired up in _Layout.cshtml. Customers.cshtml and Customers.cshtml.cs have TODO comments marking where your ADO.NET code goes. In Part 2 you'll create Products.cshtml and Products.cshtml.cs yourself, following the same pattern.
