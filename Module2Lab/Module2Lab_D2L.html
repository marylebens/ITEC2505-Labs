Background: Why .NET 10 LTS?

We're using .NET 10 LTS this semester, which stands for Long-Term Support. This is what professional developers use in production environments. Companies don't jump to the newest version the second it comes out, since that's a great way to run into bugs and compatibility issues that cost real money to fix.

.NET 10 came out in November 2025 and is stable and widely adopted across the industry. Learning on .NET 10 means you're learning what's actually running in production right now at most companies. The C# language and core .NET concepts stay pretty consistent across versions, so the skills you build here will carry forward to future versions too.

Background: What You'll Need

C# is a compiled language, which means it needs special tools to turn your code into a program that can actually run. Your Codespace already has these installed for you:

  • .NET SDK: The software development kit that includes everything needed to build and run C# applications. We're using .NET 10, the Long-Term Support version, this semester.
  • VS Code: A lightweight code editor that works great for C# development once you add the right extensions.
  • C# Dev Kit: A VS Code extension that gives you IntelliSense, which is code completion, plus debugging and error checking. You'll install this yourself in Step 2.

Background: Data Types and Operators, from Python to C#

You learned about data types and operators in Python. C# is similar, with a few differences worth knowing:

  • Python int becomes C# int, whole numbers.
  • Python float becomes C# double, decimal numbers.
  • Python str becomes C# string, text.
  • Python bool becomes C# bool, true or false.

Key difference: C# asks you to declare the type when you create a variable.

Python:

age = 25

C#:

int age = 25;

Or use var, and let the compiler figure out the type:

var age = 25; // the compiler knows this is an int

Operators work almost exactly like Python:

  • Arithmetic: +, -, *, /, % (modulus)
  • Comparison: ==, !=, <, >, <=, >=
  • Logical: && (and), || (or), ! (not)
  • Assignment: =

The syntax is almost identical to Python. Just remember to end each line with a semicolon in C#.

Step 2: Install the C# Dev Kit Extension

  1. Click the Extensions icon on the left side menu to open the Extensions Marketplace. If you don't see it, click the hamburger menu and choose View, then Extensions.
  2. In the search box at the top, type C# Dev Kit and press Enter.
  3. Click the blue Install button on the C# Dev Kit extension. This also installs the base C# extension automatically, so you're all set with one click.

Step 3: Check Your .NET Version

  1. In the terminal, type dotnet --version and press Enter. You should see something like 10.0.xxx. The exact number after 10.0 doesn't matter.
  2. Type dotnet --list-sdks and press Enter. This shows every .NET SDK installed in your Codespace.

What if you see the wrong version?

If you see 8.0 or 9.0 instead of 10.0, you can point your project at .NET 10 specifically once you've created it in Step 4.

  1. Open the HelloWorldWeb.csproj file inside your HelloWorldWeb folder.
  2. Find the line that says <TargetFramework> and change it to <TargetFramework>net10.0</TargetFramework>
  3. Save the file, then run dotnet restore in the terminal.
  4. Run dotnet build to rebuild with the correct version.

Step 4: Create Your First Web App

  1. Make sure your terminal is inside the Module2Lab folder, then type dotnet new webapp -n HelloWorldWeb and press Enter. This creates a new web app project called HelloWorldWeb.
  2. In the Explorer, click on the HelloWorldWeb folder to expand it, then click Program.cs to open it. This file sets up your web server and tells it how to run. Take a quick look, then leave it as is.
  3. Expand the Pages folder. You'll see Index.cshtml and Index.cshtml.cs, the two files we'll edit in the next step.

Step 5: Practice Declaring Variables and Using Operators

Let's actually try out the variables and operators from the Background section above, instead of just reading about them.

  1. Open Index.cshtml.cs. Inside the IndexModel class, above the OnGet method, add these variables: 
    public string FirstName = "Mary";
public int BirthYear = 1999;
public int CurrentYear = 2027;
public int Age;
  2. Change FirstName and BirthYear to your own first name and birth year.
  3. Inside the OnGet method, add this line, which uses the subtraction operator to calculate a value and assigns it to the Age variable:
    Age = CurrentYear - BirthYear;
  4. Save the file with Ctrl+S, or Cmd+S on a Mac.
  5. Open Index.cshtml and find the line <h1 class="display-4">Welcome</h1>. Replace it with this line, which uses @Model to display the variables you just declared:
    <h1 class="display-4">Welcome, @Model.FirstName! You'll turn @(Model.Age + 1) next year.</h1>
    Save the file.

Step 6: Run Your Web App

  1. In the terminal, type cd HelloWorldWeb to move into the project folder.
  2. Type dotnet run and press Enter. You should see output that looks something like this:
    info: Microsoft.Hosting.Lifetime[14]
          Now listening on: http://localhost:5000
    info: Microsoft.Hosting.Lifetime[0]
          Application started. Press Ctrl+C to shut down.
  3. Look at the bottom of your screen for a PORTS tab next to the TERMINAL tab, and click it.
  4. You'll see a row with a port number, usually a four digit number starting with 50, and a Forwarded Address. Hover over the forwarded address and click the small globe icon that appears.
  5. A new browser tab opens showing your web app, with your welcome message and your calculated age next year, using the variables and the subtraction operator you just wrote. Nice, that's your first web app running in the cloud.
  6. Go back to VS Code and press Ctrl+C in the terminal to stop the web server. Notice the port disappears from the PORTS tab once the server stops.

Quick note on ports and localhost

Picture your computer as an apartment building. The building has one street address, localhost, but inside there are lots of apartments, each with its own number, the port number. When you run a web app, it lives in one of those apartments. Your browser goes to localhost:5000, which basically means "go to this computer, knock on apartment 5000."

Port 80 is the usual default for regular websites, 443 for secure HTTPS sites, the 5000 range is common for .NET apps like ours while we're developing, and port 3000 shows up a lot with React and Node apps.

Step 7: Take a Quick Look at the Project Structure

Take a peek at the files sitting inside your HelloWorldWeb folder:

  • Program.cs: sets up your web server and configures how the app runs.
  • Pages folder: holds your web pages.
  • wwwroot folder: holds static files like CSS, JavaScript, and images.
  • HelloWorldWeb.csproj: the project file that tells .NET how to build your app.
  • obj and bin folders: hold temporary and compiled files.
  • appsettings.json: a configuration file for your app.

You won't need to edit the .csproj file or touch the obj and bin folders, but it's good to know what they're for.

Step 8: Build Your Troubleshooting Cheat Sheet

You'll run into errors eventually. Everyone does. Let's build a cheat sheet now so you have it handy all semester.

  1. In the terminal, type cd .. to move back up to the Module2Lab folder.
  2. In the Explorer, right click in the empty space under the Module2Lab folder and choose New File. Name it TROUBLESHOOTING.md. The .md extension means Markdown, a simple markup language developers use for documentation like this.
  3. Copy and paste the following into the file, then save it: 
    # C# Troubleshooting Cheat Sheet

## Check .NET Version
dotnet --version
dotnet --list-sdks

## Restore Packages
dotnet restore

## Clean and Rebuild
dotnet clean
dotnet build

## Delete bin/obj Folders
Right-click on bin and obj folders in VS Code and choose Delete, then run:
dotnet build

## Stop a Running Web Server
Press Ctrl+C in the Terminal

## Port Already in Use
- Press Ctrl+C to stop the server
- Click the PORTS tab, right-click the port, choose "Stop Forwarding Port"
- Run dotnet run again

## Common Error Messages
"The type or namespace name could not be found"
- Missing using statement or package reference
- Run dotnet restore

"The current .NET SDK does not support targeting .NET X"
- Version mismatch between SDK and project
- Check dotnet --version

"Address already in use"
- Port conflict
- Stop the previous instance with Ctrl+C or stop port forwarding

Step 10: Build the Pizza Party Calculator

Let's write a web app that uses variables and operators to figure out how many pizzas you'd need for a party.

  1. Reopen your Codespace and open the Module2Lab folder, same as Step 1 in Part 1.
  2. In the terminal, make sure you're inside the Module2Lab folder, then type dotnet new webapp -n PizzaPartyCalculator and press Enter.
  3. Type cd PizzaPartyCalculator to move into the new project folder.
  4. In the Explorer, expand the Pages folder. You'll see a pair of files both named Index, with two different extensions. Index.cshtml is the HTML file for the home page. Index.cshtml.cs is the C# file that holds the logic, the code that actually does the calculating.
  5. Open Index.cshtml.cs and replace everything in the file with this code: 
    using Microsoft.AspNetCore.Mvc;
using Microsoft.AspNetCore.Mvc.RazorPages;

namespace PizzaPartyCalculator.Pages;

public class IndexModel : PageModel
{
    [BindProperty]
    public int NumberOfGuests { get; set; }

    public int PizzasNeeded { get; set; }
    public double TotalCost { get; set; }
    public bool ShowResult { get; set; }

    public void OnGet()
    {
        ShowResult = false;
    }

    public void OnPost()
    {
        // Declare variables
        int slicesPerGuest = 3; // Assume each guest eats 3 slices
        int slicesPerPizza = 8; // Standard pizza has 8 slices
        double costPerPizza = 12.99;

        // Calculate the total number of slices needed
        int totalSlicesNeeded = NumberOfGuests * slicesPerGuest;

        // Calculate the number of pizzas required
        PizzasNeeded = (int)Math.Ceiling((double)totalSlicesNeeded / slicesPerPizza);

        // Calculate total cost
        TotalCost = PizzasNeeded * costPerPizza;
        ShowResult = true;
    }
}
  6. Now open Index.cshtml and replace everything in that file with this code. The @ symbols are called directives, and they tell the compiler that the code right after the @ symbol is C#, not HTML, so it needs to run rather than just display. HTML only formats the page, while C# code can actually do things, like calculate a pizza count. 
    @page
@model IndexModel
@{
    ViewData["Title"] = "Pizza Party Calculator";
}
<h1>Pizza Party Calculator</h1>
<p>Find out how many pizzas you need for your party!</p>
<form method="post">
    <label for="NumberOfGuests">Number of Guests:</label>
    <input type="number" id="NumberOfGuests" name="NumberOfGuests" required min="1" />
    <button type="submit">Calculate</button>
</form>
@if (Model.ShowResult)
{
    <p>For @Model.NumberOfGuests guests, you'll need @Model.PizzasNeeded pizzas.</p>
    <p>That will cost $@Model.TotalCost (at $12.99 per pizza).</p>
}
  7. In the terminal, type dotnet run and press Enter.
  8. Open the PORTS tab and click the globe icon to open your web app, same as you did in Part 1.
  9. Test your calculator. Try 10 guests, then 25, then 50, clicking Calculate each time and watching the results change.
  10. Go back to the terminal and press Ctrl+C to stop the server.
