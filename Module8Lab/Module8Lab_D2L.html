Module 8 Lab: Pokemon and LINQ

Let's learn how to query a list of data without writing a single loop by hand.

Introduction

In this lab you'll use LINQ to query a list of Pokemon and find out which ones are ready to evolve, based on their level. We're using a simple rule, level 16 or higher, but you could expand this with more properties and conditions to match the real evolution rules from the games.

Pokemon are fictional creatures trainers capture and train, forming bonds with them as they grow. Evolution happens when a Pokemon transforms into a different species, usually gaining new abilities and getting stronger.

Background: Three Parts of a Query Operation

Every LINQ query operation is really three separate steps:

  1. Obtain the data source, in our case a List of Pokemon.
  2. Create the query, the from/where/orderby/select expression that describes what you want.
  3. Execute the query, which happens when you actually loop through the results or otherwise use them. LINQ queries are lazy, they don't run until something asks for the data.

Step 1: Obtain the Data Source

Open Program.cs and replace the first TODO comment with this list of sample Pokemon:

var pokemons = new List<Pokemon>
{
    new Pokemon { Id = 1, Name = "Bulbasaur", Type = "Grass", Level = 15 },
    new Pokemon { Id = 2, Name = "Charmander", Type = "Fire", Level = 36 },
    new Pokemon { Id = 3, Name = "Squirtle", Type = "Water", Level = 10 },
    new Pokemon { Id = 4, Name = "Pikachu", Type = "Electric", Level = 22 },
    new Pokemon { Id = 5, Name = "Eevee", Type = "Normal", Level = 25 }
};

Watch your capitalization: List<Pokemon> uses an uppercase P, matching the class name. C# is case sensitive, so a lowercase pokemon would cause a build error.

Step 2: Create the Query

Replace the second TODO comment with this LINQ query, which finds every Pokemon at level 16 or higher and sorts the results by level:

var readyToEvolve = from p in pokemons
                    where p.Level >= 16
                    orderby p.Level
                    select p;

Read this almost like English: from each Pokemon p in the list, where its Level is 16 or more, order the results by Level, and select the whole Pokemon object.

Step 3: Execute the Query

Replace the third TODO comment with:

Console.WriteLine("Pokemon Ready to Evolve:");
foreach (var p in readyToEvolve)
{
    Console.WriteLine($"Name: {p.Name}, Type: {p.Type}, Level: {p.Level}");
}

This foreach loop is the moment the query actually runs. Everything before this just described what you wanted, this line is what asks for it.

Before You Run It: Predict the Output
