# ITEC2505-Labs

This repository contains starter code for the labs in the ITEC2505 Visual C# .Net Programming course.

## How to use this repository

1. Fork this repository to your own GitHub account. Do not clone it directly.
2. Create one GitHub Codespace from your fork. You will reuse this same Codespace for every lab in this course. Do not create a new Codespace for each lab.
3. Each lab has its own folder in this repository, named Module1Lab, Module2Lab, Module3Lab, and so on.
4. Open the folder for the current lab inside your Codespace and follow the steps in the lab instructions posted on D2L.
5. Always stop your Codespace when you are finished working, even if you plan to come back later the same day.
