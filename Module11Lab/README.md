# Module 11 Lab

Starter folder for the Module 11 lab, a Razor Pages app called RubberDuckStore. The Read operation (the dropdown that shows a duck's details) is already fully working, study it in Part 1. In Part 2 you'll add Create, Update, and Delete yourself, using TODO comments in RubberDucks.cshtml.cs and RubberDucks.cshtml as your guide.
