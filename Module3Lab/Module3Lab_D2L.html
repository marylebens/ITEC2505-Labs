Let's teach your app to make decisions, and satisfy a craving for Mexican food while we're at it.

Introduction

In this lab we'll explore conditional statements in C# while deciding whether to order tacos, burritos, or both, based on how hungry we are. We'll build a small web app using Razor Pages, and by the end you'll have used three different ways to write a conditional in C#: if/else if/else, the ternary operator, and switch.

Background: Understanding Razor Pages

Razor Pages is how we build web apps in ASP.NET Core. Unlike a console app that runs in the terminal, a Razor Pages app runs in a web browser.

Razor Pages use two files that work together:

  1. The .cshtml file holds your HTML markup with Razor syntax, that's the @ symbol stuff. This file displays the user interface in the browser.
  2. The .cshtml.cs file, called the code behind, holds your C# logic. This file processes the data and contains your conditional statements.

The .cshtml file can reach properties and methods from the .cshtml.cs file using the @Model keyword. When someone submits a form, the data goes to a handler method in your code behind file, which processes it and updates properties the .cshtml file can then display.

Background: Conditional Statements in C#

Here's a quick rundown of the three kinds of conditionals we'll use today.

if/else if/else statement: use if to run code when a condition is true, else if for additional conditions, and else for a default case.

if (condition1)
{
    // runs if condition1 is true
}
else if (condition2)
{
    // runs if condition2 is true
}
else
{
    // runs if neither condition matched
}

Ternary operator: a compact way to write a simple if/else. Syntax: condition ? expression1 : expression2

string result = (score >= 60) ? "Pass" : "Fail";

switch statement: compares one expression against several possible values.

switch (grade)
{
    case 'A':
        // code for grade A
        break;
    case 'B':
        // code for grade B
        break;
    default:
        // code for other grades
        break;
}

@model Module3Lab.Pages.IndexModel

    ViewData["Title"] = "Taco & Burrito Decision Maker";

<form method="post">
    <label>How hungry are you? (1-10)</label>

    <h2>Your Results:</h2>

What this file does: it creates the form where someone enters their hunger level. The @Model keyword lets us reach properties from the code behind file, and the @if (Model.ShowResults) block only shows up after someone submits the form.

Step 3: Build the C# Code Behind File (Index.cshtml.cs)

  1. Open Index.cshtml.cs and delete everything in the file.
  2. Copy and paste this code: 
    using Microsoft.AspNetCore.Mvc;
using Microsoft.AspNetCore.Mvc.RazorPages;

namespace Module3Lab.Pages
{
    public class IndexModel : PageModel
    {
        // These properties hold the data that Index.cshtml will display
        // after the user submits the form.
        public int HungerLevel { get; set; }
        public string HungerMessage { get; set; } = string.Empty;
        public string Recommendation { get; set; } = string.Empty;
        public string EncouragementMessage { get; set; } = string.Empty;
        public bool ShowResults { get; set; } = false;

        public void OnGet()
        {
            // Runs when the page first loads, before anyone has
            // entered a hunger level. Nothing to do here yet.
        }

        public void OnPost(int hungerLevel)
        {
            HungerLevel = hungerLevel;
            ShowResults = true;

            // We use two named thresholds instead of hardcoding
            // 8 and 5 directly in the if statement below. This makes the
            // conditions easier to read, and if you want to change what
            // counts as very hungry, you only have to change it in one place.
            const int veryHungryThreshold = 8;
            const int somewhatHungryThreshold = 5;

            // IF ELSE IF ELSE STATEMENT
            // C# checks each condition in order from top to bottom and
            // runs the first block that matches. Once one matches, it
            // skips the rest, even if a later condition would also be true.
            if (HungerLevel >= veryHungryThreshold)
            {
                // Runs when HungerLevel is 8, 9, or 10
                HungerMessage = "You're super hungry. Order both tacos and burritos.";
            }
            else if (HungerLevel >= somewhatHungryThreshold)
            {
                // Runs when HungerLevel is 5, 6, or 7
                // We already know it's less than 8 here, or the first
                // condition above would have matched instead.
                HungerMessage = "You're moderately hungry. Go for a plate of tacos.";
            }
            else
            {
                // Runs for anything left over, which is HungerLevel 1 through 4
                HungerMessage = "You're not that hungry. Opt for a small burrito.";
            }

            // TERNARY OPERATOR
            // This is shorthand for a simple if else that only sets one
            // value. Read it as: if HungerLevel is 5 or more, Recommendation
            // becomes "Tacos". Otherwise it becomes "Burrito".
            Recommendation = (HungerLevel >= somewhatHungryThreshold) ? "Tacos" : "Burrito";

            // SWITCH STATEMENT
            // A switch compares HungerLevel against a list of specific
            // values. Grouping several case labels together, like the 7, 8,
            // and 9 lines below, means all of those values run the same
            // block of code. The break statement tells C# to stop checking
            // once it finds a match.
            switch (HungerLevel)
            {
                case 10:
                    EncouragementMessage = "You're a taco and burrito champion.";
                    break;

                case 9:
                case 8:
                case 7:
                    EncouragementMessage = "Taco plate time.";
                    break;

                case 6:
                case 5:
                case 4:
                    EncouragementMessage = "Small burrito it is.";
                    break;

                default:
                    // Catches everything not listed above, which is 1, 2, and 3
                    EncouragementMessage = "Maybe just grab a snack.";
                    break;
            }
        }
    }
}

What this file does: this is where all your C# logic lives. OnGet() runs when the page first loads, and OnPost() runs when someone submits the form. All three kinds of conditionals live inside OnPost().
