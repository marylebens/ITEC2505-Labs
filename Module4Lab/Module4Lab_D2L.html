Module 4 Lab: Loops and Arrays at the Guthrie Theater

Let's build a show display for the Guthrie Theater, and get comfortable with two different kinds of loops.

Introduction

Today we'll build a simple Guthrie Theater show display using Razor Pages. You'll store a list of shows in an array, use a for loop to display them, and use a while loop to count how many of the titles are long. The Guthrie Theater in Minneapolis is one of the most prestigious regional theaters in the United States.

Background: What Is Bootstrap?

Bootstrap is a popular free CSS framework that makes it easy to create good looking web pages without writing a lot of CSS code yourself. Instead of writing your own styles, you add Bootstrap classes to your HTML elements. For example, class="btn btn-primary" creates a nice blue button. The W3Techs CSS framework usage survey from September 2026 found that Bootstrap is used by 74.9% of all the websites whose CSS framework could be identified. It's already linked into today's starter project for you, so you can jump straight into the C# and Razor part of the lesson.

Learning Objectives

  • While loops for counting through an array.
  • For loops for counting and displaying array contents.
  • Arrays for storing multiple values.
  • Razor Pages basics.
  • Using Bootstrap for styling.

Step 2: Update Index.cshtml.cs (Page Model)

Open Pages/Index.cshtml.cs. You'll see the class is already there with a TODO comment where you'll add your code. Replace that TODO with the following, right inside the class, above OnGet:

public string[] Shows = { "Hamlet", "Cabaret", "Fences" };
public int LongTitleCount = 0;

Now replace the TODO comment inside OnGet with this while loop:

int i = 0;
while (i < Shows.Length)
{
    if (Shows[i].Length > 5)
    {
        LongTitleCount++;
    }
    i++;
}

Step 3: Update Index.cshtml (View)

Open Pages/Index.cshtml and replace the placeholder paragraph with this code:

<div class="container mt-5">
    <h1 class="text-center">Guthrie Theater</h1>

    <h5>Current Shows:</h5>
    <ul class="list-group">
        @for (int i = 0; i < Model.Shows.Length; i++)
        {
            <li class="list-group-item">@(i + 1). @Model.Shows[i]</li>
        }
    </ul>
    <p class="mb-0 mt-3">Out of @Model.Shows.Length shows, @Model.LongTitleCount have a title longer than 5 letters.</p>
</div>

Understanding the Code

Array: stores the three show titles.

public string[] Shows = { "Hamlet", "Cabaret", "Fences" };

For loop: walks through the array once to display every title.

@@for (int i = 0; i < Model.Shows.Length; i++)

While loop: walks through the array a different way, using its own counter variable that you increase by hand inside the loop, and counts titles longer than 5 letters.

int i = 0;
while (i < Shows.Length)
{
    if (Shows[i].Length > 5)
    {
        LongTitleCount++;
    }
    i++;
}

container, mt-4, mb-3, card, list-group are all Bootstrap classes: container centers content and adds padding, mt/mb add margin to the top or bottom, card creates a bordered box, and list-group creates a nice looking list.

Step 4: Run and Test Your Program

  4. Confirm the count of long titles below the list looks right. Hamlet and Fences are 6 letters, Cabaret is 7, so the count should read 3.

Refresher: what just happened when you typed dotnet run

When you type dotnet run, your Codespace starts a web server, a background program that sits and waits for a browser to ask it for a page. That server picks a port to listen on, a number that works like an apartment number at the address localhost, so your browser knows exactly where to knock.

The PORTS tab is where you see that port number and get a clickable web address, a URL, that points your browser at it. When you click the globe icon, your browser sends a request to that URL, the web server receives it, runs your Razor Page code, builds the HTML for the page, and sends it back. That's the page you see.

When you press Ctrl+C in the terminal, you're telling the web server to shut down, which is why the port disappears from the PORTS tab and the page stops loading if you refresh it.

Step 6: Reopen Your Codespace and Add a Ticket Prices Array

  2. Open Pages/Index.cshtml.cs inside your Module4Lab project folder.

    public double[] TicketPrices = { 89.00, 65.00, 72.50 };

Step 7: Write Your Own for Loop

Open Pages/Index.cshtml. Right after the closing </ul> from Step 3, add a new heading, <h5>Ticket Prices:</h5>, followed by your own list.

Write your own @for loop, following the same pattern as the show list above it, that walks through TicketPrices and displays a list item for each show's name and price together, something like Hamlet: $89.00. You already have both arrays lined up in the same order, so the loop counter that works for one works for the other too.

Step 8: Write Your Own while Loop

Open Pages/Index.cshtml.cs. Add a new property called ExpensiveShowCount, an int.

Inside OnGet, following the same pattern as the while loop that counts long titles, write your own while loop that counts how many ticket prices are $70.00 or higher, and stores the result in ExpensiveShowCount.

Step 9: Display the Count

Back in Index.cshtml, add a paragraph after your ticket price list that displays ExpensiveShowCount, following the same pattern as the long title count paragraph in Step 3.

Before You Run It: Predict the Output
