Module 6 Lab: Creating a Teen Hangout Web App

Let's put classes, arrays, loops, and conditionals to work together in a real web page.

Introduction

Today we'll build a "Teen Hangout" site, a safe, fun spot for teens to socialize online. This lab pulls together everything you've learned so far: C# classes, arrays, loops, conditionals, and a web based GUI using Razor Pages. Get ready to put it all to work.

In this lab, you will:

  • Create C# classes to represent teen users and their posts.
  • Use arrays to store multiple users and posts.
  • Use loops to display that data.
  • Use a conditional to filter content.
  • Build a Razor Pages interface to display it all.

Before You Start

You'll need your GitHub account and your one shared Codespace from the Module 1 Lab. If you haven't finished that lab yet, go do that first, then come back here. If you haven't signed up for the GitHub Student Developer Pack yet, this is still a good week to knock that out, on the Student Developer Pack signup page.

Step 2: Build the User Class

Open User.cs and replace the TODO comment with this code:

public string Username { get; set; }
public int Age { get; set; }
public string FavoriteColor { get; set; }

public User(string username, int age, string favoriteColor)
{
    Username = username;
    Age = age;
    FavoriteColor = favoriteColor;
}

Step 3: Build the Post Class

Open Post.cs and replace the TODO comment with this code:

public string Username { get; set; }
public string Content { get; set; }
public int Likes { get; set; }

public Post(string username, string content, int likes)
{
    Username = username;
    Content = content;
    Likes = likes;
}

Step 4: Build the Index Page Model

Open Pages/Index.cshtml.cs. Replace the first TODO comment with:

public User[] Users { get; set; }
public Post[] Posts { get; set; }

Now replace the second TODO comment, inside OnGet, with this code, which creates an array of users and an array of posts:

// Create array of users
Users = new User[]
{
    new User("MusicLover", 15, "Purple"),
    new User("GamerGirl", 16, "Red"),
    new User("BookwormBen", 15, "Yellow")
};

// Create array of posts
Posts = new Post[]
{
    new Post("GamerGirl", "Anyone want to play online later?", 30),
    new Post("BookwormBen", "Reading the best book ever!", 15),
    new Post("MusicLover", "Concert next week! So excited!", 22)
};

Step 5: Build the Index Page

Open Pages/Index.cshtml and replace the placeholder paragraph with this code:

<div class="container mt-4">
    <h1 class="text-center text-primary">Teen Hangout</h1>
    <p class="text-center">Your virtual space to connect!</p>

    <div class="card my-4">
        <div class="card-body">
            <h2>Our Members</h2>
            @for (int i = 0; i < Model.Users.Length; i++)
            {
                <div class="alert alert-secondary">
                    <strong>@Model.Users[i].Username</strong> -
                    Age: @Model.Users[i].Age -
                    Favorite Color: @Model.Users[i].FavoriteColor
                </div>
            }
        </div>
    </div>

    <div class="card my-4">
        <div class="card-body">
            <h2>Recent Posts</h2>
            @for (int i = 0; i < Model.Posts.Length; i++)
            {
                <div class="alert alert-info">
                    <strong>@Model.Posts[i].Username</strong>
                    <p>@Model.Posts[i].Content</p>
                    <small>Likes: @Model.Posts[i].Likes</small>
                </div>
            }
        </div>
    </div>
</div>

Step 6: Run and Test Your Application

  1. In the terminal, type dotnet run and press Enter.
  2. Open the PORTS tab, hover over the forwarded address, and click the globe icon to open your app.
  3. Confirm you see a list of members and a list of recent posts.
  4. When you're done testing, go back to the terminal and press Ctrl+C to stop the server.

Refresher: what's happening on the server

Every time your browser loads this page, the web server runs OnGet, builds the Users and Posts arrays fresh in memory, then hands the finished HTML back to your browser through the URL and port you clicked in the PORTS tab. Nothing is saved anywhere. Refresh the page and OnGet runs all over again with the same sample data.

Part 2: At Home

You'll write your own loop and your own conditional this time, using the exact same skills from Part 1.

In Part 1 you typed loops that were already written out for you. Now you'll write your own version of a loop with a conditional filter, plus a loop that adds things up, both applied to the same app. This is required, not optional, since writing the code yourself is what actually builds the skill.

Step 8: Reopen Your Codespace

Go to GitHub's home page, sign in, and reopen your existing Codespace, same as Step 1.

Step 9: Write Your Own Filtered Loop

Open Pages/Index.cshtml. Add a new card below the Recent Posts card, following the same card, card-body, and h2 structure, titled "Popular Posts (20+ Likes)".

Inside that card, write your own for loop, following the same pattern as the Recent Posts loop above it, that walks through Model.Posts. Add an if statement inside the loop, following the same pattern from Module 3, that only displays a post, using the alert alert-success class instead of alert-info, when that post's Likes is 20 or higher.

Step 10: Write Your Own Total Likes Loop

Open Pages/Index.cshtml.cs. Add a new property called TotalLikes, an int.

Inside OnGet, after the Posts array is created, write your own loop, following the same for loop pattern from Module 4's while loop and this module's for loops, that adds up the Likes from every post in the Posts array and stores the total in TotalLikes.

Step 11: Display the Total

Back in Index.cshtml, add a paragraph after your Popular Posts card that displays TotalLikes, something like "Total likes across all posts: @Model.TotalLikes".

Before You Run It: Predict the Output
